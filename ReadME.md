
# Retail Sales & Customer Analytics

## Project Overview
This project analyzes retail sales data using Python, Pandas, SQL, and data visualization to understand sales performance, customer behavior, and product trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- SQLite and SQL
- VS Code

## Project Work
- Explored the dataset and checked data quality.
- Analyzed sales by customer segment and product sub-category.
- Studied monthly and yearly sales trends.
- Identified top customers by sales.
- Practiced SQL queries for filtering, grouping, sorting, and aggregation.

## Key Findings
- Technology generated the highest sales among the three product categories.
- The Consumer segment contributed approximately 50.76% of total sales.
- Phones was the highest-selling product sub-category.
- Annual sales were highest in 2018.

Ongoing — additional analysis and dashboard development are planned.
