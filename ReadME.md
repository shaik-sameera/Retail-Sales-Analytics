# Retail Sales Analytics

## Project Overview

This project focuses on analyzing retail sales data
using Python, SQL, and Power BI to identify business
trends and generate meaningful insights.

## Dataset

- Approximately 9,800 records
- 18 columns
- Includes order dates, sales, products,
  customer segments, and regions.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- SQLite
- Power BI

## Key Analysis

- Data cleaning and exploratory data analysis
- Sales performance by product category
- Customer segment analysis
- Regional sales comparison
- Yearly sales trends
- Customer and product analysis using SQL

## Power BI Dashboard

An interactive dashboard featuring:
- Total Sales
- Average Sales
- Total Orders
- Unique Customers
- Category, segment, and regional analysis
- Yearly sales trends
- Interactive slicers

## Key Findings

- Total sales were approximately 2.26 million.
- Technology recorded the highest category sales.
- Consumer customers contributed approximately
  50.76% of total sales.
- 2018 recorded the highest annual sales.

## Project Outcome

This project demonstrates the use of Python,
SQL, and Power BI to transform retail sales data
into useful business insights.
